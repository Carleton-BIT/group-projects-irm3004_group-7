# Group # 7's project

The goal of this project is to help students at Carleton university improve their on campus life. Our service will offer information about clubs and services here on Carleton Unviersities great campus. Anything from mental health, sporting clubs and academic services will be avaliable here. The information we will offer is, physical location (building or room #). Hours of operation and if avaliable a link to there website/ description of what this service can help with. Careleton has so many great resources for students a major challenge for students is finding them, our application mains to change that narrative. This will help both students and services grow and prosper
